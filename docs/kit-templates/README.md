# Templates

This directory contains reusable templates, checklists, and documents for Direct Primary Care practices.

## Directory Structure

```
kit-templates/
├── spreadsheets/    # Excel/CSV financial and tracking templates
└── documents/       # PDF and document templates
```

## Spreadsheet Templates

Located in `/spreadsheets/`:

- Financial projections and calculators
- Patient tracking sheets
- Comparison matrices for vendors
- Budgeting tools
- Pricing calculators

## Document Templates

Located in `/documents/`:

- Membership agreements
- Patient consent forms
- HIPAA notices
- Employment agreements
- Business Associate Agreements
- Office policies

## Usage

1. Download the template you need
2. Review the included instructions (if any)
3. Customize for your practice
4. Have legal counsel review agreements before use

## Contributing Templates

When adding new templates:

1. Use descriptive file names with `template-` prefix
2. Include instructions within the file or in a companion README
3. Note any state-specific considerations
4. Update this README with the new template description
