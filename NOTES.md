# Notes

A free-form scratchpad for half-formed thoughts, observations, and
reminders that aren't ready to be GitHub issues yet.

## How to use this file

- **Capture freely.** If a thought might otherwise be forgotten, it goes
  here. Low bar.
- **Promote to issues when ready.** When a note becomes concrete and
  actionable, open a GitHub issue for it and delete the note (or move
  it to the "Promoted" section below with a link to the issue).
- **Prune regularly.** Stale notes are worse than no notes. If something
  has been sitting untouched for a month and you no longer care, delete it.
- **Don't duplicate issues.** If something is already an open issue,
  don't re-list it here. GitHub is the system of record for tracked work.

**This file is intentionally not part of the published site** — it lives
at the repo root, not in `docs/`. See [`CLAUDE.md`](CLAUDE.md) for the
full explanation of how work is tracked across files and issues.
