## About the DPC Mentor Platform

The DPC Mentor Platform is a separate application that connects mentors and mentees. This section of the DPC Startup Kit provides the supporting resources and documentation that platform members reference.

For mentor applications, profile management, and mentee connections, visit the DPC Mentor Platform application directly.
