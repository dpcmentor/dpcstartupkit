## Important Disclaimer

These templates are provided as starting points only. Direct Primary Care regulations vary by state, and legal requirements change over time.

**Always have an attorney licensed in your state review and customize these documents before use.**

## Usage Notes

- Templates are provided in PDF format
- Editable versions (Word/Google Docs) may be available for some templates
- State-specific variations are noted where applicable
- Review all templates annually for compliance updates

## Contributing

When adding document templates:

1. Use `template-` prefix in filename
2. Note any state-specific requirements
3. Include version date in document footer
4. Provide both PDF and editable format when possible
